Phase 1: Resend Account & API Key Setup
Create an Account: Go to Resend.com and sign up for a free account (which gives you 3,000 free emails/month).
Generate an API Key:
Navigate to API Keys in your Resend dashboard.
Click Create API Key, name it mossaic-production, and give it Full Access (or sending access).
Copy the key immediately (it starts with re_...) and save it securely. You will need it for Cloudflare.
Sender Domain Note:
For initial testing, you can use Resend's verified test sender: onboarding@resend.dev.
For production branding, you can verify your custom domain (mossaic.in) in Resend later so emails come directly from noreply@mossaic.in.
Phase 2: Deploying the Cloudflare Worker
Cloudflare Workers provide a zero-maintenance, globally distributed serverless environment that securely hides your Resend API key and enforces CORS safety.
Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/), navigate to Workers & Pages, and click Create application -> Create Worker. Name it mossaic-contact-api.
Open the online code editor for your worker and paste the following production script:
JavaScript
export default {
  async fetch(request, env, ctx) {
    // 1. Define allowed origins (Your GitHub Pages domain or custom domain)
    const allowedOrigin = "https://mossaic.in"; // Change/add your github.io domain if testing there first

    const corsHeaders = {
      "Access-Control-Allow-Origin": allowedOrigin,
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type",
    };

    // Handle CORS preflight requests
    if (request.method === "OPTIONS") {
      return new Response(null, { headers: corsHeaders });
    }

    // Restrict to POST requests only
    if (request.method !== "POST") {
      return new Response(JSON.stringify({ error: "Method Not Allowed" }), {
        status: 405,
        headers: { ...corsHeaders, "Content-Type": "application/json" },
      });
    }

    try {
      const body = await request.json();
      const { name, email, message, gotcha } = body;

      // 2. Anti-Spam Honeypot Check: If the hidden 'gotcha' field is filled, silently block it
      if (gotcha) {
        return new Response(JSON.stringify({ success: true }), {
          status: 200,
          headers: { ...corsHeaders, "Content-Type": "application/json" },
        });
      }

      // 3. Basic Validation
      if (!email || !message) {
        return new Response(JSON.stringify({ error: "Email and message are required fields." }), {
          status: 400,
          headers: { ...corsHeaders, "Content-Type": "application/json" },
        });
      }

      // 4. Send email via Resend API
      const resendResponse = await fetch("https://api.resend.com/emails", {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${env.RESEND_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          from: "mossAIc Contact <onboarding@resend.dev>", // Replace with your domain email once verified
          to: ["contact@mossaic.in"], // Where you want to receive inquiries
          subject: `New Inquiry from ${name || "Website Visitor"}`,
          html: `
            <div style="font-family: Arial, sans-serif; padding: 20px; color: #333;">
              <h2 style="color: #0284c7;">New Website Inquiry — mossAIc</h2>
              <p><strong>Name:</strong> ${name || "Not provided"}</p>
              <p><strong>Email:</strong> ${email}</p>
              <p><strong>Message:</strong></p>
              <blockquote style="background: #f4f4f5; padding: 12px; border-left: 4px solid #0284c7; margin: 0;">
                ${message.replace(/\n/g, '<br>')}
              </blockquote>
            </div>
          `,
        }),
      });

      if (!resendResponse.ok) {
        const errorData = await resendResponse.json();
        throw new Error(errorData.message || "Failed to dispatch email transmission.");
      }

      return new Response(JSON.stringify({ success: true, message: "Message sent successfully!" }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" },
      });

    } catch (err) {
      return new Response(JSON.stringify({ error: err.message }), {
        status: 500,
        headers: { ...corsHeaders, "Content-Type": "application/json" },
      });
    }
  },
};
Set your Worker Secret:
In your Cloudflare Worker settings, go to Settings -> Variables.
Under Environment Variables, click Add variable.
Set the variable name to RESEND_API_KEY, paste your Resend API key value, toggle it to Encrypt / Secret, and click Save.
Deploy: Click Save and Deploy. Note your worker's live URL (e.g., [https://mossaic-contact-api.your-subdomain.workers.dev](https://mossaic-contact-api.your-subdomain.workers.dev)).

2. Frontend JavaScript Handler
Add this script to handle form submission asynchronously, manage button loading states, and display success/error feedback:
JavaScript
<script>
  const WORKER_URL = 'https://mossaic-contact-api.your-subdomain.workers.dev'; // Replace with your Cloudflare Worker URL

  document.getElementById('mossaic-contact-form').addEventListener('submit', async (e) => {
    e.preventDefault();

    const submitBtn = document.getElementById('form-submit-btn');
    const statusEl = document.getElementById('form-status');
    
    // Gather values
    const payload = {
      name: document.getElementById('form-name').value,
      email: document.getElementById('form-email').value,
      message: document.getElementById('form-message').value,
      gotcha: e.target.querySelector('input[name="gotcha"]').value
    };

    // UI Loading State
    submitBtn.disabled = true;
    submitBtn.textContent = 'Sending Message...';
    statusEl.classList.add('hidden');

    try {
      const response = await fetch(WORKER_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(payload)
      });

      const result = await response.json();

      if (!response.ok) {
        throw new Error(result.error || 'Failed to send message.');
      }

      // Success state
      statusEl.textContent = '✓ Message sent successfully! We will get back to you soon.';
      statusEl.className = 'text-xs text-center font-mono mt-2 text-emerald-400';
      statusEl.classList.remove('hidden');
      e.target.reset();

    } catch (err) {
      // Error state
      statusEl.textContent = `✕ Error: ${err.message}`;
      statusEl.className = 'text-xs text-center font-mono mt-2 text-rose-400';
      statusEl.classList.remove('hidden');
    } finally {
      submitBtn.disabled = false;
      submitBtn.textContent = 'Send Message ↗';
    }
  });
</script>

Commit your updated HTML/JS files to your repository and push them to GitHub.
Your GitHub Actions workflow will automatically compile and deploy your static site to GitHub Pages.
Visit your live site (mossaic.in), fill out the contact form, and submit it. You should instantly receive the formatted email in your inbox (contact@mossaic.in), complete with zero exposed API keys and robust spam protection
